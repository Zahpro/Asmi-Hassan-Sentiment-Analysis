# Asmi-Hassan-Sentiment-Analysis

This project analyzes audience comments on the Iraqi drama "Asmi Hassan" using Python.

## Steps
- Preprocessing Arabic text (tokenization, stopword removal)
- a Custom Sentiment Lexicon for Iraqi sentiment analysis (positive/negative words)
- Visualization with Matplotlib & Seaborn

## Libraries Used
- Pandas, NumPy
- arabic reshape
- Matplotlib, Seaborn
